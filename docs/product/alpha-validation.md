# PropNest Frontend — Internal Alpha

The internal alpha begins after Phase 2 and runs for 2–3 months using the family's real rental properties.

## Rule

No major new features during the alpha window.

## Frontend validation goals

Observe:

- dashboard usefulness
- payment-entry speed
- billing-state clarity
- receipt retrieval
- correction/reversal workflows
- unnecessary clicks/data entry
- responsive/mobile usability
- confusing or missing information

Problems found during alpha become separate issues rather than uncontrolled scope expansion.

The alpha is a validation gate for deciding which Phase 3+ frontend work has real value.
