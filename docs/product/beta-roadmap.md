# PropNest Frontend — Beta Roadmap Context

The PropNest product roadmap originated as a backend issue set. The frontend repository keeps a lightweight copy of that roadmap so frontend work can remain aligned with backend delivery phases.

## Phase sequence

```text
Phase 1
  Foundation
       ↓
Phase 2
  Lease → Billing → Payment → Receipt → Dashboard
       ↓
Internal Alpha
  2–3 months on real family rental properties
       ↓
Phase 3+
  Owner / Tenant / Maintenance / Leasing / Agent / Accounting / AI / Integrations
```

The complete product intent comes from the backend roadmap. Frontend implementation details are documented in `roadmap.md` and the phase-specific documents in this directory.

## Important rule

This file is **roadmap context**, not a claim that those UI features currently exist.
